🍃 1. Cuadros de Diálogo (Alert & Prompt)

Repaso Teórico:

JavaScript permite interactuar con el usuario mediante ventanas emergentes nativas del navegador. prompt() sirve para capturar texto escrito por el usuario, confirm() evalúa un cuadro de aceptación (verdadero/falso), y alert() muestra un mensaje informativo en pantalla.
Alert

Aprendiendo JavaScript

Captura de nombre y edad mediante cuadros de diálogo interactivos.

Ver código clave
let nombre = prompt('Escribe tu nombre');\nalert("Mi nombre es: " + nombre);
Ejecutar Práctica
Alert

División de Dos Números

Cálculo de cociente solicitando valores numéricos con validación.

Ver código clave
let divi = numero1 / numero2;\nalert(divi);
Ejecutar Práctica
Alert

Multiplicación de Dos Números

Cálculo de producto utilizando operador de multiplicación.

Ver código clave
let multiplicacion = numero1 * numero2;\nalert(multiplicacion);
Ejecutar Práctica
Alert

Resta de Dos Números

Cálculo de diferencia numérica mediante prompts y alertas.

Ver código clave
let resta = numero1 - numero2;\nalert(resta);
Ejecutar Práctica
Alert

Suma de Dos Números

Operación básica de adición reflejada en alerta emergente.

Ver código clave
let suma = numero1 + numero2;\nalert(suma);
Ejecutar Práctica

🍃 2. Bucle Do...While

Repaso Teórico:

El bucle do...while es similar al while, con la gran diferencia de que ejecuta el bloque de código al menos una vez antes de evaluar la condición que se encuentra al final.
Do While

Mostrar números del 1 al 5

Bucle iterativo con verificación posterior para conteo ascendente.

Ver código clave
do { texto += i; i++; } while (i <= 5);
Ejecutar Práctica
Do While

Mostrar números del 5 al 1

Conteo regresivo implementado con estructura do...while.

Ver código clave
do { texto += i; i--; } while (i >= 1);
Ejecutar Práctica
Do While

Mostrar números pares del 2 al 10

Secuencia de números pares incrementando de 2 en 2.

Ver código clave
do { texto += i; i += 2; } while (i <= 10);
Ejecutar Práctica
Do While

Sumar números del 1 al 5

Acumulador de valores numéricos en un rango predefinido.

Ver código clave
do { suma = suma + i; i++; } while (i <= 5);
Ejecutar Práctica

Repaso Teórico:

document.write() permite escribir texto o etiquetas HTML directamente en el flujo del documento HTML del navegador. Es útil para prácticas sencillas de visualización de resultados.
Document Write

Datos Estudiante

Captura y despliegue estructurado de datos personales y académicos.

Ver código clave
document.write("Nombre : " + nombre);\ndocument.write("<br>Edad : " + edad);
Ejecutar Práctica
Document Write

Operaciones Básicas

Cálculo simultáneo de suma, resta, multiplicación y división.

Ver código clave
suma = n1 + n2;\nresta = n1 - n2;\nmultiplicacion = n1 * n2;\ndivision = n1 / n2;
Ejecutar Práctica

🍃 4. Manipulación del DOM (Document Object Model)

Repaso Teórico:

El DOM conecta la página web con JavaScript. Permite modificar el contenido con innerHTML, buscar elementos por su identificador único con getElementById(), o utilizar selectores avanzados con querySelector().
DOM - getElementById

Modificar Texto de Elemento

Actualización del contenido de texto mediante el ID del elemento.

Ver código clave
var elemento = document.getElementById("aviso");\nelemento.textContent = "Hola Estudiantes";
Ejecutar Práctica
DOM - getElementById

Modificar Estilos CSS

Cambio dinámico de propiedades de estilo (color de fondo) en un botón.

Ver código clave
document.getElementById("btn").style.backgroundColor = "lightblue";
Ejecutar Práctica
DOM - innerHTML

Inyección de Texto HTML

Modificación de contenido estructurado dentro de contenedores.

document.getElementById("mensaje").innerHTML = "¡Bienvenido!";

DOM - innerHTML

Inyección de Etiquetas (Imagen)

Carga y renderizado dinámico de una imagen mediante etiqueta HTML.

Ver código clave

Ejecutar Práctica
DOM - querySelector

Selección por Selector CSS

Modificación de propiedades en elementos seleccionados por clase.

Manipulación del estado interactivo (disabled) de un botón.

🍃 5. Estructuras Condicionales (If / Else If)

Repaso Teórico:

Permiten tomar decisiones lógicas en el código. Si la condición del if se cumple, ejecuta un bloque; si no, evalúa alternativas con else if o ejecuta una opción por defecto con else.
Else If

Registro con Confirmación

Validación mediante cuadro de diálogo confirm para recolectar datos.

Ver código clave
const continuar = confirm('¿Desea registrar tus datos?');\nif(continuar) { ... } else { alert('Tengo flojera'); }
Ejecutar Práctica
Else If

Evaluación de Promedio

Comprobación de calificación aprobatoria mayor o igual a 6.

Ver código clave
if(promedio >= 6) { document.write("Aprobado"); } else { document.write("Reprobado"); }
Ejecutar Práctica
Else If

Validación de Edad para Votar

Comprobación de mayoría de edad (>= 18 años).

Ver código clave
if(edad >= 18) { document.write("YA PUEDES VOTAR"); } else { document.write("AÚN NO"); }
Ejecutar Práctica
Else If

Comparación de Dos Números

Estructura condicional anidada para determinar mayor, menor o igualdad.

Ver código clave
if(num1 > num2) { ... } else if(num2 > num1) { ... } else { ... }
Ejecutar Práctica
Else If

Número Positivo, Negativo o Cero

Evaluación del signo matemático de un número ingresado.

Ver código clave
if(num1 > 0) { ... } else if(num1 < 0) { ... } else { ... }
Ejecutar Práctica

🍃 6. Bucle For

Repaso Teórico:

El bucle for se utiliza cuando se conoce de antemano el número exacto de veces que se desea repetir un bloque de instrucciones. Consta de tres partes: inicialización, condición y actualización.
Bucle For

Mostrar números del 1 al 10

Secuencia numérica ascendente controlada por bucle for.

Ver código clave
for (let i = 1; i <= 10; i++) { document.write(i); }
Ejecutar Práctica
Bucle For

Tabla de Multiplicar del 2

Generación automatizada de productos de la tabla del 2.

Ver código clave
for (let i = 1; i <= 10; i++) { document.write("2 x " + i + " = " + (2 * i)); }
Ejecutar Práctica
Bucle For

Números Impares del 1 al 9

Secuencia numérica con incremento de 2 en 2.

Ver código clave
for (let i = 1; i <= 9; i += 2) { document.write(i); }
Ejecutar Práctica
Bucle For

Sumar números del 1 al 10

Acumulación total de valores en un ciclo definido.

Ver código clave
for (let i = 1; i <= 10; i++) { suma = suma + i; }
Ejecutar Práctica

🍃 7. Funciones en JavaScript

Repaso Teórico:

Una función es un bloque de código reutilizable diseñado para realizar una tarea específica. Pueden recibir valores de entrada mediante parámetros y devolver un resultado utilizando la instrucción return.
Funciones JS

Función Simple 1

Invocación de una función básica sin parámetros que muestra alerta.

Ver código clave
function mensaje() { alert("Bienvenido a funciones en JS"); }\nmensaje();
Ejecutar Práctica
Funciones JS

Función Simple 2 (Saludar)

Declaración de función modular para saludo general.

Ver código clave
function saludar() { document.write("HOLA MUNDO"); }\nsaludar();
Ejecutar Práctica
Funciones JS

Función por Grupos Académicos

Reutilización de bloques de código recibiendo distintos grupos.

Ver código clave
function saludo(grupo) { document.write("hola " + grupo); }\nsaludo('5 AVP');
Ejecutar Práctica
Funciones JS

Obtener el Doble (Con Retorno)

Uso de la instrucción return para devolver un valor calculado.

Ver código clave
function obtenerDoble(n) { return n * 2; }\nobtenerDoble(7);
Ejecutar Práctica
Funciones JS

Saludo Personalizado con Parámetros

Envío de argumentos de nombres para saludos dinámicos.

Ver código clave
function saludo(nombre) { document.write("hola " + nombre); }\nsaludo('Maria de Jesus');
Ejecutar Práctica

🍃 8. Estructura Switch

Repaso Teórico:

La estructura switch evalúa una expresión y compara su valor contra múltiples casos (case). Si encuentra coincidencia, ejecuta el bloque correspondiente hasta encontrar un break.
Switch

Asignación de Semestres y Laboratorios

Evaluación multi-caso para determinar el laboratorio correspondiente.

Ver código clave
switch (semestre) {\n    case 1: ... break;\n    case 2: case 3: case 4: ... break;\n}
Ejecutar Práctica
Switch

Menú de Operaciones Básicas

Selección de operaciones aritméticas mediante un menú de opciones.

Ver código clave
switch (opcion) {\n    case 1: suma = n1 + n2; break;\n    case 2: resta = n1 - n2; break;\n}
Ejecutar Práctica

🍃 9. Bucle While

Repaso Teórico:

El bucle while ejecuta un bloque de instrucciones de manera repetitiva mientras una condición especificada se mantenga verdadera. Es ideal cuando no se conoce el número de iteraciones de antemano.
Bucle While

Mostrar números del 1 al 5

Estructura iterativa con condición previa para conteo.

Ver código clave
while (i <= 5) { document.write(i); i++; }
Ejecutar Práctica
Bucle While

Mostrar números pares del 2 al 10

Bucle while con incremento de 2 en 2.

Ver código clave
while (i <= 10) { document.write(i); i = i + 2; }
Ejecutar Práctica
Bucle While

Contar del 10 al 1

Cuenta regresiva utilizando decremento en bucle while.

Ver código clave
while (i >= 1) { document.write(i); i--; }
Ejecutar Práctica
Bucle While

Sumar números del 1 al 5

Acumulación de valores numéricos en bucle condicional.

Ver código clave
while (i <= 5) { suma = suma + i; i++; }
Ejecutar Práctica
