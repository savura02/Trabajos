🌱 Guía de Estudio: Primer Parcial (HTML)

Estructuras Web, Maquetación, Tablas y Formularios

🍃 1. Estructura y Maquetación Web

Repaso Teórico:

HTML (HyperText Markup Language) utiliza etiquetas para estructurar las páginas web. La etiqueta <div> es un contenedor genérico en bloque fundamental para agrupar elementos y darles diseño con CSS.
Div

Práctica Div

Uso de contenedores y bloques HTML para distribución de diseño.

Ver código clave
<div style="background: #f0f0f0;">\n    <h3>Contenedor Div</h3>\n</div>
Ejecutar Práctica
Estructura HTML

Estructura Base

Maquetación inicial con etiquetas semánticas y organización de documentos.

Ver código clave
<!DOCTYPE html>\n<html lang="es">\n<head>...</head>\n<body>...</body>\n</html>

🍃 2. Navegación, Listas y Tablas

Repaso Teórico:

Las tablas en HTML se construyen con <table>, filas <tr>, celdas de datos <td> y encabezados <th>. Los hipervínculos <a> permiten navegar entre páginas mediante rutas relativas o absolutas.
Hipervínculos y Listas

Página Principal

Implementación de enlaces de navegación internos y listas ordenadas/desordenadas.

Ver código clave
<ul>\n    <li><a href="principal.html">Inicio</a></li>\n</ul>
Ejecutar Práctica
Horario

Horario de Clase

Diseño tabular organizado para mostrar materias y horas escolares.

Ver código clave
<table border="1">\n    <tr><th>Hora</th><th>Lunes</th></tr>\n</table>
Ejecutar Práctica
Tablas

Tabla HTML

Estructuración avanzada con filas (`tr`), celdas (`td`) y encabezados (`th`).

Ver código clave
<table>\n    <tr><td>Dato 1</td></tr>\n</table>

Tabla Periódica de Elementos

🍃 3. Multimedia, Formularios y Extras

📖 Repaso Teórico:

HTML5 incluye etiquetas nativas como <video> y <audio> para reproducir contenido multimedia. Los formularios (<form>) recolectan información del usuario mediante inputs de texto, botones y campos de selección.
Multimedia

Video y Audio

Incrustación de elementos multimedia nativos en HTML5.

Ver código clave
<video controls>\n    <source src="video.mp4" type="video/mp4">\n</video>
Ejecutar Práctica
Formulario

Formulario de Registro

Captura de datos con inputs, etiquetas, botones y campos de selección.

Ver código clave
<form>\n    <label>Nombre:</label>\n    <input type="text" name="nombre">\n</form>
